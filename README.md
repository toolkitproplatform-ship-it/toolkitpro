## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- PostgreSQL 14+
- Redis 6+ (Optional)
- Git

### Installation

```bash
# ১. Repository ক্লোন করুন
git clone https://github.com/yourusername/toolkit-pro.git
cd toolkit-pro

# ২. Dependencies ইনস্টল করুন
npm install

# ৩. Environment Variables সেট করুন
cp .env.example .env
# .env ফাইল খুলে সব মান বসান

# ৪. Database Migrate করুন
npm run db:migrate

# ৫. Database Seed করুন (২৫০০+ টুল)
npm run db:seed

# ৬. Development সার্ভার চালু করুন
npm run dev
